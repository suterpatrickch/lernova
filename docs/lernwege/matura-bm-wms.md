# Lernweg: Matura / BM / WMS

<div class="ln-profile"><strong>Kurzprofil:</strong> Prüfungsnähe, Transfer, Fallstudien, Wirtschaftspolitik, Rechtsfälle, FRW</div>


=== "🟢 Verstehen"

- Matura: Modelle, Begriffe, Argumentation, Transfer
- BM/WMS: Handlungssituationen, Fälle, Praxis, Anwendungen
- Prüfung: Operatoren, Zeit, Struktur, Musterlösung
- Kompetenz: erklären, anwenden, begründet beurteilen

=== "🔵 Anwenden"

**Training:** Baue pro Thema eine Aufgabe in drei Stufen.

- Verstehen: Begriff / Modell
- Anwenden: Fall / Rechnung / Grafik
- Beurteilen: Urteil / Empfehlung / Zielkonflikt

=== "🟣 Beurteilen"

**Beurteilen:** Was unterscheidet gute von sehr guten Antworten?

- Präzision: Fachbegriffe, saubere Darstellung, richtige Norm
- Transfer: neue Situation, Modellgrenzen, Perspektiven
- Urteil: Begründung, Gegenargument, Abwägung, Schlussfolgerung
