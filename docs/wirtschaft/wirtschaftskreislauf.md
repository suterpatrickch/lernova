# Wirtschaftskreislauf

<div class="ln-profile"><strong>Kurzprofil:</strong> Haushalte, Unternehmen, Staat, Banken, Ausland, Güterstrom, Geldstrom</div>


=== "🟢 Verstehen"

- Haushalte: Arbeit, Einkommen, Konsum, Sparen
- Unternehmen: Produktion, Investition, Löhne, Verkauf
- Staat: Steuern, Leistungen, Regulierung, Infrastruktur
- Banken: Spargelder, Kredite, Zinsen, Zahlungsverkehr
- Ausland: Import, Export, Wechselkurse, Abhängigkeiten

=== "🔵 Anwenden"

**Aufgabe:** Zeichne einen einfachen Kreislauf mit Haushalt und Unternehmen.

- Güterstrom: Arbeit, Güter, Dienstleistungen, Ressourcen
- Geldstrom: Lohn, Konsumausgaben, Preise, Einkommen

=== "🟣 Beurteilen"

**Beurteilen:** Was fehlt im Kreislaufmodell?

- Umwelt: Ressourcenverbrauch, Emissionen, externe Effekte
- Care-Arbeit: unbezahlte Arbeit, Haushalt, Betreuung
- Verteilung: Einkommen, Vermögen, Ungleichheit
- Staat: Umverteilung, Regulierung, öffentliche Güter
