# Rechtsfälle lösen

=== "🟢 Verstehen"

- Sachverhalt: Personen, Ereignisse, Daten, Belege
- Rechtsfrage: Streitpunkt, Anspruch, Pflicht, Problem
- Norm: Gesetzesartikel, Tatbestand, Rechtsfolge, Ausnahme
- Subsumtion: Anwendung, Begründung, Prüfung, Schluss

=== "🔵 Anwenden"

**Mini-Fall:** Ein Kunde reklamiert eine defekte Lieferung.

- Aufgabe: Formuliere Rechtsfrage und passende Normen.
- Lösungsschritte: Sachverhalt, Artikel, Anwendung, Ergebnis

=== "🟣 Beurteilen"

**Beurteilen:** Warum gibt es oft nicht sofort «die» richtige Lösung?

- Unklarheit: Sachverhalt, Beweis, Auslegung, Ermessensspielraum
- Interessen: Parteien, Fairness, Risiko, Verhältnismässigkeit
- Urteil: vertretbare Lösung, bessere Begründung, offene Fragen
