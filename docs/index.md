# Lernova

**Verstehen. Anwenden. Beurteilen.**  
Eine schlanke, kursartige Lernplattform für Wirtschaft & Recht auf Sekundarstufe II.

<p class="ln-lead">Lernova ist keine Materialablage. Jede Lernseite führt durch drei Denkstufen, reduziert sichtbaren Text und öffnet Details erst dann, wenn sie gebraucht werden.</p>
