## Was ist an diesem PoC wichtig?

- Jede Lernseite hat genau drei Bereiche: **Verstehen – Anwenden – Beurteilen**.
- Externe Ressourcen erscheinen als **kuratiertes Lernmaterial**, nicht als Linkfriedhof.
- KI wird als **Bring-your-own-AI** gedacht: Lernova liefert Prompts, die Lernende in ihre eigene KI kopieren können.
- Die Seite ist statisch und kann gratis auf GitHub Pages oder Cloudflare Pages gehostet werden.
