# Grundfragen des Wirtschaftens

<div class="ln-profile"><strong>Kurzprofil:</strong> Bedürfnisse, Güter, Knappheit, Produktionsfaktoren, ökonomisches Prinzip</div>


=== "🟢 Verstehen"

- Bedürfnisse: Grundbedürfnisse, Wahlbedürfnisse, Konsumwünsche, Wertewandel
- Güter: freie Güter, knappe Güter, Sachgüter, Dienstleistungen
- Knappheit: Ressourcen, Zeit, Geld, Zielkonflikte
- Ökonomisches Prinzip: Minimalprinzip, Maximalprinzip, Optimumprinzip

**Realitätscheck:** Viele politische Entscheidungen sind Knappheitsentscheidungen.

- Klimapolitik: Kosten, Nutzen, Generationen, Verantwortung
- Gesundheit: Prämien, Leistungen, Solidarität, Eigenverantwortung
