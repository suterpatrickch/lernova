# Versicherungen verstehen

## Lebenssituation

Du lässt versehentlich das Handy einer Kollegin fallen. Das Display ist kaputt.

## Worum geht es?

Versicherungen schützen vor finanziellen Folgen bestimmter Risiken. Nicht jede Versicherung deckt alles.

## Lern-Nugget

Eine Versicherung funktioniert so: Viele zahlen Prämien ein, damit einzelne Personen im Schadenfall unterstützt werden können.

## Aufgabe

Welche Versicherung könnte bei einem Schaden an fremdem Eigentum relevant sein?

??? success "Lösung anzeigen"
    Häufig ist die Privathaftpflichtversicherung relevant. Ob sie zahlt, hängt vom konkreten Vertrag und den Bedingungen ab.

## Merksatz

Versicherungen ersetzen nicht Vorsicht, aber sie können grosse finanzielle Risiken abfedern.
