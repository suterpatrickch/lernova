# Grundfragen des Wirtschaftens

<div class="ln-profile"><strong>Kurzprofil:</strong> Bedürfnisse, Güter, Knappheit, Ressourcen, Entscheidungen, Verantwortung</div>

<div class="ln-lesson"><span class="chip basis">1L Basis</span></div>

=== "🟢 Verstehen"

- Bedürfnisse: Grundbedürfnisse, Wahlbedürfnisse, Individualbedürfnisse, Kollektivbedürfnisse
- Güter: freie Güter, knappe Güter, Sachgüter, Dienstleistungen
- Knappheit: Ressourcen, Zeit, Geld, Zielkonflikte
- Ökonomisches Prinzip: Minimalprinzip, Maximalprinzip, Optimumprinzip

- Alltagssituation: Taschengeld, Konsum, Sparen, Verzicht
- Entscheidung: Alternativen, Nutzen, Kosten, Opportunität
- Beispielanalyse: Handykauf, Ferienjob, Budget, Prioritäten
